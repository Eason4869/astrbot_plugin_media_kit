## Implementation and rulings

- Baseline: Python 3.12, 85 original tests passed in 7.081 seconds.
- GitHub parser: public repository/issue/PR/release facts and bounded details;
  anonymous by default, optional Token, separate parse/image proxy settings.
- Detail command: existing permissions and output modes, independent link
  quota namespace, shared user quota; archive requests original details only.
- Optional summaries: existing AstrBot/custom connection adapter, independent
  of translation enablement; bounded input/output, timeout and model-aware cache.
- Ruling: defer Taobao entirely because anonymous item page and detail API
  probes returned bootstrap/risk content, not verifiable product data. This
  follows the user's explicit acceptance gate; cost is no Taobao support in
  this version. Existing Xianyu short-link ownership stays unchanged.
- Ruling: ship JD's verified modern product-page path with explicit partial
  data and wind-control limits. Numeric/short/mobile recognition does not
  imply all links work; a tested numeric link remained blocked after the
  30-second isolated browser attempt. Price is explicitly unavailable in the
  verified sample; no recommendation price is substituted.
- Ruling: do not bypass non-public/fake-IP DNS results for GitHub avatars.
  Fact parsing works, and cards fall back to the author's initial. Cost is
  missing avatars on affected local DNS setups; existing README networking
  guidance explains real-DNS deployment requirements.
